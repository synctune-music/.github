# Synctune Music

Synctune Music is a branch of [Synctune](https://github.com/synctune-io), focused on modern software for music creation, discovery, and collaboration. We build tools for making music and connecting the people around it.

## Projects

| Repository | Focus |
| --- | --- |
| [studio-duo](https://github.com/synctune-music/studio-duo) | An open-source digital audio workstation for recording, production, mixing, and mastering. |
| [scream-forge](https://github.com/synctune-music/scream-forge) | A vocal effects plugin for music production. |
| [yt2karaoke](https://github.com/synctune-music/yt2karaoke) | Turn YouTube videos into karaoke experiences. |
| [track2stem](https://github.com/synctune-music/track2stem) | Separate audio tracks into stems. |
| [anytrack-converter](https://github.com/synctune-music/anytrack-converter) | Convert audio files and YouTube media between formats locally. |
| [find-concerts-io](https://github.com/synctune-music/find-concerts-io) | Concert discovery. |
| [every-music](https://github.com/synctune-music/every-music) | Find band members and collaborators through musician profiles and open calls. |
| [devoidofbeauty.com](https://github.com/synctune-music/devoidofbeauty.com) | The Devoid of Beauty artist website. |
| [b143ck.music](https://github.com/synctune-music/b143ck.music) | A music website. |

Repository links use their planned organization locations. Some may be private or pending transfer.
